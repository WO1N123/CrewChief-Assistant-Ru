# Обновления CrewChief Assistant RU

Приложение использует GitHub как публичный канал обновлений и не требует отдельного сервера лицензирования.

## Стабильный канал

Метаданные текущей стабильной версии хранятся в корневом файле `update.json`.

Для каждой новой версии:

1. увеличить версию приложения;
2. собрать `CrewChiefRU_Setup.exe`;
3. создать GitHub Release с тегом вида `v0.9.5`;
4. прикрепить к Release файл с точным именем `CrewChiefRU_Setup.exe`;
5. обновить `update.json` в ветке `main`.

## Проверка приложением

Будущий встроенный обновлятор сравнивает установленную версию со значением `version` в `update.json`. Если версия новее, он получает соответствующий Release по тегу из `tag` и скачивает asset с именем из `asset`.

Перед запуском обновления приложение должно корректно остановить распознавание речи, MQTT и другие фоновые службы, скачать установщик во временную папку, проверить загруженный файл и только после этого запустить установку.

## Лицензирование

Отдельная система лицензий не используется. Исходный код проекта публикуется по лицензии MIT.
