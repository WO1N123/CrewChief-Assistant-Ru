CREWCHIEF RU BUILDER 0.9.2

PYTHON RUNTIME FIX

- Исправлена ситуация, когда официальный установщик Python завершался с кодом 0, но python.exe отсутствовал в ожидаемой папке.
- Сборщик больше не удаляет зарегистрированную установку Python перед повторным запуском установщика.
- Добавлен поиск рабочего 64-битного Python 3.11 через PEP 514, стандартные папки, PATH и Python Launcher.
- Параметры установки Python теперь передаются установщику явно, а не только через unattend.xml.
- Для генератора голосов создаётся отдельное изолированное окружение venv311; пакеты пользователя не изменяются.
- Если зарегистрированная установка повреждена, выполняется безопасная попытка Repair без удаления пользовательского Python.
- Сохраняются python-install.log и, при необходимости, python-repair.log.
- Проверка цифровой подписи Python Software Foundation сохранена.
- uv.exe, uvx.exe и uvw.exe не используются.

UI CONTROLS

- Сохранены современные тёмные полосы прокрутки и ползунок громкости из версии 0.9.1.

OUTPUT

- В output создаётся только CrewChiefRU_Setup.exe.
