# CrewChief Assistant RU

Русскоязычный голосовой ассистент для **Crew Chief** под Windows 10/11 x64.

> Проект не является официальной частью Crew Chief.

## Текущая версия

**0.9.4**

## Возможности

- русское распознавание голосовых команд;
- голоса Silero Eugene и Xenia;
- ответы по телеметрии Crew Chief через MQTT;
- назначаемая кнопка Push-to-Talk;
- приоритет штатных сообщений Crew Chief;
- современный WPF-интерфейс;
- светлая и тёмная темы;
- отдельный установщик для Windows 10/11 x64.

## Установка

Готовые версии публикуются во вкладке **Releases**.

1. Откройте последний Release.
2. Скачайте `CrewChiefRU_Setup.exe`.
3. Запустите установщик.

## Исходный код

Исходники приложения, установщика и Builder находятся в этом репозитории. Основной код расположен в `files/src/`.

Для сборки на Windows запустите:

```bat
MAKE_SETUP.cmd
```

После успешной сборки установщик появится в:

```text
output\CrewChiefRU_Setup.exe
```

Сборщик не использует `uv`, `uvw` или `uvx`.
