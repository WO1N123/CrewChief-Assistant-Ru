# CrewChief RU

Русскоязычный голосовой ассистент для CrewChief с локальным распознаванием речи, голосами Silero и получением телеметрии CrewChief через MQTT.

## Возможности

- русское распознавание голосовых команд;
- push-to-talk с назначаемой клавишей;
- голоса Eugene и Xenia;
- эффект радиосвязи;
- приоритет штатных сообщений CrewChief;
- ответы по телеметрии: шины, тормоза, топливо, круги, позиции, флаги и другие доступные данные;
- светлая и тёмная темы;
- отдельный графический установщик;
- Windows 10 x64 1809+ и Windows 11 x64.

## Установка

Установка очень простая:

1. Откройте раздел [Releases](https://github.com/WO1N123/CrewChief-Assistant-Ru/releases).
2. Скачайте файл `CrewChiefRU_Setup.exe` из последнего релиза.
3. Запустите скачанный `.exe` и следуйте инструкциям установщика.

Для обычной установки не нужно скачивать исходный код, устанавливать Python, .NET SDK или вручную запускать какие-либо скрипты.

## Сборка из исходников

1. Скачайте или клонируйте репозиторий.
2. Запустите `MAKE_SETUP.cmd`.
3. Дождитесь завершения сборки.
4. Готовый установщик появится в:

```text
output\CrewChiefRU_Setup.exe
```

Сборщик использует изолированный официальный Python 3.11.9 и не требует установленного в системе Python.

## Журналы

- `build.log` — журнал сборки;
- `builder-startup.log` — диагностика запуска сборщика;
- `%LOCALAPPDATA%\CrewChiefRUAssistant\logs\installer.log` — журнал установщика;
- `%LOCALAPPDATA%\CrewChiefRUAssistant\logs\application.log` — журнал приложения.
